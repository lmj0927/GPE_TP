## 포스터 본문 초안 (복사·다듬어 사용)

### 1. 게임 동작 방식

올라오지마왕은 플레이어가 화면에 나타나지 않고, 화면 상단에서 세 가지 장애물을 배치해 아래로 올라오는 용사를 막는 역할 전환형 수직 클라이머입니다. 용사는 머신러닝이 제어하는 이동과 점프로 플랫폼을 오르며, 낙하·튕김·구름 장애물과 바닥에서 올라오는 용암을 동시에 피해야 합니다. 용사의 체력을 모두 깎으면 플레이어가 승리하고, 용사가 맨 위 목표에 도달하면 플레이어가 패배합니다.

### 2. 기술적 특징

본 프로젝트는 Unity ML-Agents의 PPO 알고리즘으로 클라이머 정책을 학습한 뒤, ONNX 형식으로 빌드에 탑재해 실시간 추론만 수행합니다. 학습 시에는 휴리스틱 스포너 봇이 플레이어 대신 장애물을 의도적으로 배치하고, 클라이머는 8차원 정규화 벡터 관측과 Ray Perception 센서, 지상·공중·피격 상태 머신을 통해 판단합니다. 스테이지별 난이도는 별도 AI 로직이 아니라 서로 다른 학습 체크포인트 ONNX를 교체하는 방식으로 조절합니다.

### 3. 게임 조작

마우스 왼쪽 클릭으로 클릭한 가로 위치에 맞춰 Faller와 Roller를 화면 상단에서 떨어뜨립니다. Bouncer는 클릭 후 드래그한 방향으로 발사하며, 너무 수평에 가까운 각도는 제한됩니다. 키보드 1·2·3으로 장애물 종류를 바꾸고, 쿨다운이 긴 스킬 사용 후에는 자동으로 Faller 모드로 돌아가 연속 입력 부담을 줄였습니다. 스폰 전에는 점선·화살표로 낙하·굴림 경로를 미리 보여 줍니다.

### 4. 게임 플레이

인트로와 메인 메뉴를 거쳐 레벨을 선택하면, 매 판 무작위로 이어 붙인 타워 맵에서 플레이가 진행됩니다. Height Bar로 목표까지의 높이를, HP Bar와 스킬바로 전투 상황을 확인합니다. 레벨이 올라갈수록 더 많은 step으로 학습된 ONNX가 로드되어, 같은 조작으로도 맞추기 어려운 회피 패턴을 보여 줍니다. 클리어 시 플레이 시간·스폰·명중 통계와 별 등급이 표시되고, 진행도는 저장됩니다.

### 5. 기획·기술 차별화

Donkey Kong식 ‘플레이어가 위에서 방해한다’는 역할 반전에 Jump King식 수직 압박과 쿨다운 퍼즐을 결합했습니다. 규칙 기반 적 AI가 아니라 강화학습으로 **회피와 상승을 동시에** 익힌 정책을 사용해, 단순히 빠른 적이 아니라 ‘슬쩍 피하는’ 연출을 목표로 했습니다. 동적 맵 생성으로 반복 플레이 시에도 경로가 달라집니다.

### 6. 생성형 AI 활용

기획 단계에서는 ChatGPT와 Gemini로 메카닉·알고리즘 초안을 보조했고, Ludo.ai와 업스케일러로 픽셀 에셋 초안을 만든 뒤 Pixel Studio와 Photoshop에서 게임에 맞게 수정했습니다. 구현 단계에서는 Cursor로 C# 코드 작성·리팩터링을 지원받았으며, AI 결과물은 그대로 제출하지 않고 팀이 검수·통합했습니다.

## 주의사항

- 발표 PDF의 **Slime** → 포스터에서 **Roller**로 통일  
- PPT 텍스트 **그대로 복사 금지** — 위 초안을 문장으로 다시 쓰기  
- `.ai` 저장 전 모든 이미지 **Embed** 확인 (File → Package / 링크 패널 점검)  
- Walkthrough 영상에 **AI 회피·3종 장애물·승리/패배** 반드시 포함  
- ONNX **Fallback** 로그는 “빌드에서 의도된 inference 동작”으로 한 줄 설명 가능
